# Blueprint Lab 动态学习版 3.0

沿用原网站的 8 节课程、34 个步骤，适用于原有 Vercel 项目。动态交互在浏览器中运行，无需登录、后端、第三方依赖或 API Key。

## 新增体验

- 步骤导航：逐步阅读、上一步/下一步、阅读位置恢复。只有手动勾选“我已在 UE5 中完成”才会确认实作。
- 动态节点：点击节点查看职责，顺序讲解可播放、暂停、逐个推进和重置；纯数据与执行关系分别说明。
- 八课实验台：运行输出、移动朝向、镜头距离、起跳/松开/落地、奔跑结束恢复、血量 Clamp、范围开门、HUD 比例与零分母。实验操作联动节点反馈。
- 五份关键步骤素材：逐引脚说明可切换图表区域，17 个真实截图任务均标为待制作，Paper2D 与十二生肖 Demo 仍为后续规划。
- 笔记自动保存；学习记录可导出 JSON，并通过文件选择或粘贴 JSON 合并恢复。已有完成记录不会被导入的 false 清空，不同笔记会追加。
- 课程搜索覆盖节点名称，分类和关键词随 URL 保存。支持键盘操作、窄屏布局和减少动效偏好。

## 更新原 Vercel 网站

1. 保留当前仓库的旧版本记录。
2. 将本包内的全部 15 个文件复制到原网站仓库根目录，替换同名文件并加入新文件。不要再套一层 blueprint-lab-dynamic 目录，也不要只上传 ZIP。
3. 提交到原 Vercel 项目连接的分支。继续使用原项目与域名，按原设置部署。
4. 打开原网址，刷新后检查首页、课程、节点讲解和实验台；新版资源使用 v=3.0.0 缓存参数。

线上发布状态以 GitHub 提交和 Vercel 部署记录为准。

## 原学习记录

课程数据 data.js 与核对的原版逐字节一致。课程 ID、34 个步骤的顺序和 blueprintlab:v1:<课程 ID> 布尔数组记录保持原样。只要仍在同一个网站域名、同一浏览器中，旧的勾选记录会继续被读取。

新增阅读位置使用 blueprintlab:view:v1:<课程 ID>；笔记使用 blueprintlab:notes:v1:<课程 ID>。本地预览与线上网站属于不同地址，二者的浏览器记录不会自动同步，可用备份导入导出迁移。

## 电脑本地预览

电脑已安装 Node.js 时，双击“启动本地预览.cmd”，然后在浏览器打开窗口显示的 http://localhost:4289。关闭该窗口即可停止预览。无需安装依赖。也可直接打开 index.html，部分浏览器可能限制本地文件的记录保存，推荐使用本地预览入口。

## 文件说明

- index.html / courses.html / lesson.html：学习首页、课程目录、课程页。
- data.js：原 8 课和 34 步课程内容。
- app.js：页面、步骤、进度、笔记与备份交互。
- graph.js：动态概念图、节点讲解和素材标签页。
- lab.js：八课概念实验台和自测。
- backup.js：备份数据校验与合并。
- material-data.js：五份素材规格与后续路线，不含本地文件路径。
- style.css / dynamic.css / favicon.svg：基础样式、动态工作台样式和原站点图标。
- server.cjs / 启动本地预览.cmd：可选本地预览。Vercel 部署仍是静态网站，不依赖这两个文件运行后端。

## 素材与教学边界

节点连线和角色、门、血条均是程序绘制的概念示意，不是 UE5 编辑器截图或真实引擎运行。真实截图的 src 仍为空，图片任务不显示虚假的图片。第 8 课工作台按“角色主动调用 UpdateHP”展示，统一了原示意链与操作步骤的表达。

没有交付 UE5 工程、生肖 Sprite/Flipbook、Paper2D 关卡或多人同步实现。截图规格需要确定引擎小版本后在编辑器实际搭建、编译、运行和拍摄。

浏览器验证了 37 项交互；1440 / 768 / 390 / 375 像素的首页、目录和全部八课，共 40 组未发现横向溢出、缺失标题或低于 11px 的可见文字。脚本语法、数据一致性、备份合并/拒绝无效数据等 18 项检查通过；源码风格检查 0 FAIL / 0 WARN。

备份导出已实际下载并校验；粘贴 JSON 导入已实际验证保留原进度与两份笔记。内置浏览器的文件选择自动化未完成端到端确认，文件导入与粘贴导入使用相同校验与合并逻辑。已提供减少动效样式，未改变系统偏好做实机验证。

独立视觉检查脚本因系统拒绝启动浏览器而未完成；实际页面检查使用内置浏览器。未进行 UE5 引擎测试、真机手机测试或线上 Vercel 部署验证。
